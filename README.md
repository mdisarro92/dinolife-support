# DinoLife — Public Support

Official public support and privacy website for **DinoLife**, a cozy dinosaur companion game for iPhone and iPad by Michael Disarro.

- [Support website](https://mdisarro92.github.io/dinolife-support/)
- [Privacy policy](https://mdisarro92.github.io/dinolife-support/privacy.html)
- Support email: [m.disarro92@gmail.com](mailto:m.disarro92@gmail.com?subject=DinoLife%20Support)

This repository contains **only public static website files**. The DinoLife game source and assets are maintained separately in a private repository.

## GitHub Pages

Publish from branch `main`, folder `/(root)` in **Settings → Pages**. The site uses standalone HTML and CSS, with no build step or runtime dependencies.

## Updating the site

Website source files originate in the private DinoLife project's `ReleaseAssets/support-site/` folder. Review and copy approved changes into this repository before public release.
